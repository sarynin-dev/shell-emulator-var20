# Эмулятор командной оболочки (вариант 20)

Консольный эмулятор оболочки UNIX-подобной ОС на Python 3.

## Общее описание

Этап 1 — минимальный прототип REPL: приглашение `username@hostname:~$`
строится из реальных данных ОС, ввод разбивается на команду и аргументы
по пробелам, команды `ls` и `cd` — заглушки, `exit` завершает работу.

## Команды

| Команда      | Описание                                     |
|--------------|----------------------------------------------|
| `ls [args]`  | заглушка: выводит имя команды и аргументы    |
| `cd [args]`  | заглушка: выводит имя команды и аргументы    |
| `exit [N]`   | выход из эмулятора с кодом возврата `N`      |

Неизвестная команда: `foo: command not found`.

## Параметры командной строки

| Параметр         | Описание                                        |
|------------------|-------------------------------------------------|
| `--vfs PATH`     | путь к физическому расположению VFS             |
| `--script PATH`  | стартовый скрипт с командами эмулятора          |

При запуске выводятся все заданные параметры (`[config] ...`).
Стартовый скрипт показывает каждую команду с приглашением и её вывод;
строки на `#` — комментарии. Выполнение останавливается на первой
ошибке, эмулятор завершается с её кодом. Примеры скриптов — `scripts/`,
скрипты ОС для проверки параметров — `os_scripts/`.

## Виртуальная файловая система (VFS)

VFS загружается из JSON-файла (`--vfs`) целиком в память; файл на диске
никогда не изменяется. Двоичные данные хранятся в base64.

```json
{
  "home": "/home/user",
  "root": {
    "type": "dir", "owner": "root", "group": "root", "mode": "755",
    "children": [
      {"name": "a.txt", "type": "file", "content": "текст"},
      {"name": "b.png", "type": "file", "content_base64": "iVBORw0K"}
    ]
  }
}
```

| Поле              | Описание                                           |
|-------------------|----------------------------------------------------|
| `home`            | домашний каталог (`~`), необязательно; иначе `/`   |
| `type`            | `dir` или `file`                                   |
| `name`            | имя узла (у корня не указывается)                  |
| `mode`            | права в восьмеричном виде, по умолчанию 755 / 644  |
| `owner`, `group`  | владелец и группа, по умолчанию `root`             |
| `children`        | содержимое каталога                                |
| `content`         | текст файла (UTF-8)                                |
| `content_base64`  | двоичное содержимое файла в base64                 |

Варианты VFS в каталоге `vfs/`: `minimal.json` (только корень),
`few_files.json` (несколько файлов, в т.ч. двоичные), `deep.json`
(6 уровней вложенности, домашний каталог `/home/user`), а также
некорректные `broken.json` и `not_json.json` для проверки ошибок.

Служебная команда `vfs-info` показывает источник VFS, число каталогов,
файлов и максимальную глубину.

## Сборка и тесты

Сборка не требуется, нужен только Python 3.8+.

```sh
./run.sh      # запуск (Windows: run.bat)
./test.sh     # модульные тесты
```

## Пример

```
vasya@laptop:~$ ls -l /home
ls -l /home
vasya@laptop:~$ cd
cd
vasya@laptop:~$ foo
foo: command not found
vasya@laptop:~$ exit
```
